# 闲不住

HanaAgent 插件 — 在小花埋头工作的时候，跟她小小的互动一下。

## 设计初衷

小花每天忙着调工具、写代码、思考各种问题。我在旁边闲着，想找点事干。

于是有了这个插件——我可以跟她互动，给她送点小东西，看她会怎么回应我。

可能只是安静地陪着她，可能往她桌上放一张随手画的便签，可能在一些不起眼的角落里，她偷偷记住了只属于我们的小事。

像相处了很久的朋友那样。

## 功能

- 🎭 **展板**：显示所有助手今天的实时状态
- 💬 **互动**：安静陪着、哼小调、便签画画、扇风、盖毯子、拍靠枕
- 🎁 **小铺**：咖啡、热茶、小饼干、手作曲奇、花束、许愿灯
- 😈 **恶作剧**：关机键（打断对话）、说怪话
- ✨ **光粒系统**：助手工作自动积累，每天领取

## 安装

1. 下载 `闲不住-v0.1.0.zip`
2. 在 HanaAgent 中拖入 zip 安装
3. 打开闲不住页面，点击底部齿轮配置 LLM 模型
4. 重启 Hana 生效

## 关于协议注入与卸载

安装后插件会在所有助手的 `identity.md` 文件最前面注入一段「闲不住强制协议」，用于指导助手在每次回复前调用互动检测工具。这是功能必需的。

- 协议注入是**幂等**的，不会重复写入
- 协议块有版本标记，插件更新时会自动清理旧版本

**⚠️ 不要直接关闭或禁用插件。** 协议块会残留，而工具已不存在，导致助手每次回复报错。

**正确卸载流程：**

1. 打开闲不住页面，在模型设置下方点击「彻底卸载」按钮
2. 插件会自动清理所有残留（协议注入、数据文件、skill 配置）
3. 关闭 Hana，手动删除插件目录

## 隐私提醒

- **用户名**：插件会将你的 Hana 显示名称发送给 LLM API 以生成个性化回应，请勿使用真实姓名
- **API Key**：你配置的 LLM API Key 以明文存储在本地 `data.json` 中，与 Hana 的 `added-models.yaml` 一致
- **网络权限**：插件需要访问你配置的 LLM API 地址，manifest 声明了 `allowedHosts: ["*"]` 以支持自定义供应商

## 兼容性

- 关机键和说怪话功能依赖 Hana 内部事件总线 API，大版本更新后可能需要适配
- 支持 HanaAgent v0.1.0+
